## 三网精品线路到底有什么区别？一分钟看懂

如果你打算认真挑一台新加坡 CN2 VPS，这三个缩写得认脸。

### CN2：电信用户的"高速通道"

CN2 全称是中国电信下一代承载网，分 CN2 GT 和 CN2 GIA 两个等级。GT 是半程 CN2，到了国际段就回到普通骨干；GIA 是全程 CN2，从落地一直优化到出口。**真正意义上的"精品 CN2"，通常指的是 CN2 GIA**。电信用户走这条线，晚高峰依然能稳住带宽，不会像 163 那样一过 8 点就抽风。

### AS9929：联通的 A 网

9929 是中国联通的精品国际线路，俗称"A 网"，相比普通 169 骨干，拥塞控制做得好得多。**联通用户走 9929，晚上看 4K 不卡的概率比 169 高一个量级**。这条线在很多 CN2 VPS 上是和电信 CN2 配套出现的，缺了它联通用户体验就会塌。

### CMIN2：移动用户的新希望

CMIN2 是中国移动国际网络二线（China Mobile International Network 2），比老的 CMIN 更稳，**移动用户走 CMIN2，新加坡到广东移动实测延迟能压到 34ms 左右**，比走普通国际出口快太多。这也是为什么很多移动用户专门找带 CMIN2 的新加坡机房。

一句话总结：**单走 CN2 只讨好电信用户，三网都优化才是真·全家桶**。这也是为什么 GoMami 这类主打三网精品的商家能在新加坡这个节点上杀出来。
